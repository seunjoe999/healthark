## Usage

These are **subagents** — Claude Code can spawn them autonomously for specialized tasks, or you can reference them explicitly:

```
Use the postgres-pro agent to optimize this query.
Dispatch the security-auditor agent to review this PR.
Ask the technical-writer agent to document this API.
```
